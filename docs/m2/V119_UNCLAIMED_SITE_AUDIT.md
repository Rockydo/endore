# v119 unclaimed canonical-site audit

## Purpose

This M2 political pass prevents nearest-seat allocation from turning ruins, independent
highlands, and canonically emptied lands into the territory of a nearby playable realm.
It does not redraw any broad border, change map geometry, or add a fictional state.

## Contracted sites

The following named locations must remain `WILD` at TA 3018: Tharbad, Ost-in-Edhil, Lond
Daer, Sarn Ford, the Eagles' Eyrie, Framsburg, the Grey Mountain ruins, the Withered
Heath, the Dead Marshes, Dagorlad, Emyn Arnen, Morgai, Cirith Gorgor, and Shelob's Lair.

Sources: *The Lord of the Rings*, Book I Chs. 2–7; Book II Ch. 2; Book IV Chs. 2–3 and
8–9; Appendix A; Appendix B; *The Hobbit*, Chs. 6–7; and the exact Arda Maps/ArdaCraft
coordinates held in `m3_landmarks.csv`.

## Actual corrections

Only two cells changed in this pass:

- Eagles' Eyrie: Beornings → wild.
- Framsburg: Gundabad → wild.

The remaining entries already matched the intended TA 3018 state and are now protected
against future allocation drift. Mordor's neighbouring fortress cells remain separately
owned; this contract applies only to the source-exact outer-pass locations.

The Eagles' Eyrie is additionally an explicit empty landmark in M5. It must not acquire
the generic wilderness population assigned to ordinary passable land: the inhabitants
are Eagles, not a mortal polity or settlement. Framsburg already remains an empty ruin.
